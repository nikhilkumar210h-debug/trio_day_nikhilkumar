DATA & PRIVACY

Your data. Clear rules.

Last updated: 23 September 2026. This page describes the current Challenge, Stories, Chat and profile behavior implemented in the app.

01

Account

Firebase Authentication handles sign-in identity. The app stores basic profile data such as display name, photo, permanent Trio UID and bio in Firestore.

Email is kept in the private user record rather than the public profile document.

02

Challenges

Challenge answers are stored per user and Challenge so the app can show community totals and your current selection.

Challenge discussion messages are public to signed-in users. You can delete your own discussion messages.

03

Stories & media

Stories can include text and supported media. Story metadata is stored in Firestore; media uses the configured media provider used by the app.

Story visibility can be public or limited to the selected audience where the current UI provides that control.

04

Private Chat

Private Chat is one-to-one. Messages are stored under the two participating Firebase user IDs and access is restricted by the Firestore rules.

Do not use Chat or Stories to share passwords, one-time codes, financial information or private addresses.

05

Progress

Challenge participation can update XP, level, streak and badges through server-authoritative gamification. Those protected fields are not client-writable.

06

Your controls

The current UI exposes profile, story, chat and Challenge discussion controls where supported. Account and privacy questions should be reviewed against the deployed Firebase, media, retention and moderation configuration before public launch.

Important

This is product documentation, not a legal privacy notice. Before public launch, align it with the actual deployed services, retention policy, moderation process and applicable privacy/age requirements.
